# Повний перелік сторінок Dashboard — 3.25.0

Завершено 13 із 42 UI-сторінок; залишилось 29 UI-сторінок та 3 перевірки redirects.

45 page.tsx-маршрутів: 42 сторінки з UI та 3 маршрути перенаправлення.
API (124 route.ts-файли), robots.txt, not-found.tsx, error.tsx і global-error.tsx
не підміняють цей перелік: системні межі враховано окремо на етапі 6.
Таблиця описує фактичні файли й імпортовані UI-компоненти; JSON поруч містить
джерела, розмір сторінок до міграції, форми, інлайн-стилі й auth-сигнали.

Важлива розбіжність документації: чинний `/` перенаправляє на `/raids`.
