# shared

`@mistblossom/discord-contract` — спільний контракт Discord-взаємодій.

Локальний пакет, який підключають і панель, і бот через `file:../shared`.

## Що всередині

- розбір і кодування `custom_id` (`mbv1:...`);
- перелік доменів взаємодій і зіставлення `custom_id` з доменом;
- валідація рядків компонентів Discord перед відправкою.

## Навіщо окремий пакет

Бот вирішує, куди відправити взаємодію, а панель — що з нею робити. Обидва
розбирають один і той самий рядок `custom_id`. Поки це була копія в кожному
сервісі, розбіжність між ними не давала жодної помилки: кнопка просто
переставала працювати, і причину шукали то в боті, то в панелі.

Тому будь-яка зміна формату `custom_id` робиться тут і рівно один раз.

## Обмеження Discord

`custom_id` не може перевищувати 100 символів, а в одному повідомленні не
може бути двох компонентів з однаковим `custom_id` — Discord відхиляє таке
повідомлення з 400. Перевірки на це є у `validateInteractionComponents`.

## Меню рейду (contract 1.1.0)

`raid-menu` відкриває особистий вибір, `raid-draft` змінює збережену чернетку, `raid-form` відкриває нативну форму, `raid-save` приймає Modal Submit. `decodeRaidSignupMenuId` визначає ці дії як RAID. `raidSignupModalFor` будує type 9 без читання бізнес-даних. Бот відповідає формою лише на підписану кнопку в особистому повідомленні належного сервера; dashboard перевіряє власника й ревізію чернетки при підтвердженні. Старі ID лишаються розпізнаваними для переходу на нове меню. Оновлювати dashboard і bot разом.

## Вибір і підтвердження запису (контракт 1.1.1, dashboard 3.8.89)

Приватне меню використовує raid-draft для вибору способу, персонажа або окремо класу та спеціалізації. Зміна вибору оновлює лише чернетку. Кнопка raid-form відкриває форму участі, ролі та нагадування без HTTP-запиту до dashboard; її підтвердження raid-save зберігає запис через захищену чергу.

Повні модальні форми raid-modal і їхні raid-save із параметрами mode/page залишаються для вже опублікованих повідомлень 3.8.87–3.8.88. Підготовка такої форми виконується підписаним внутрішнім запитом до dashboard без мутації запису в рейд. Нове меню не створює кнопок із поділом спеціалізацій на сторінки.
