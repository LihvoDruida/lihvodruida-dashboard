# Markdown-редактор правил Статика

Оновлена реалізація зберігає правила як Markdown у вже наявному полі `staticRulesConfig/main.text`.
Міграція бази даних не потрібна: старі звичайні тексти відображаються як абзаци без небезпечного HTML.

- Редактор: `/discord/static`, доступний **лише відповідальному РЛ та адміністратору/власнику**.
- Публічний перегляд: `/static/accept?t=…`, без авторизації, але з поточними перевірками токена.
- Кнопки: заголовок, підзаголовок, **жирний**, *курсив*, список, нумерація, цитата, код, посилання.
- Три режими: Markdown, розділений перегляд, попередній перегляд.
- Імпорт `.md`, `.markdown`, `.txt` (до 20 000 символів), експорт `.md`.
- Вихідні правила передаються окремим приватним файлом `Правила_Статика.md`, **не вбудованим у публічний репозиторій**. Завантажте цей файл через кнопку імпорту в редакторі й натисніть **Зберегти правила**. До збереження поточні правила на сайті не змінюються.
- Рендерер спільний для попереднього перегляду, сторінки РЛ (лише читання) та публічного прийняття.
- Підтримано заголовки, жирний/курсив/закреслення, абзаци, списки, цитати, блоки коду, `http(s)`-посилання та прості таблиці.
- HTML у Markdown не інтерпретується. Рядки JavaScript/data в посиланнях відображаються як текст.
- Збереження зміненого Markdown автоматично підвищує номер версії правил. Права та 24-годинні запрошення незмінні.

Перевірка рендерера незалежно від наявних скриптів:

```bash
cd dashboard
node scripts/check-static-markdown-independent.cjs
```
