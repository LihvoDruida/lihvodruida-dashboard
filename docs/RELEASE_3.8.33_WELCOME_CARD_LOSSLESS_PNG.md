# 3.8.33 — Lossless PNG compression for the welcome card

- Фінальна welcome-картка кодується PNG з адаптивною построковою фільтрацією та zlib level 7 замість level 3 без фільтрації. Стиснення повністю без втрат: без palette/квантизації, декодовані RGBA-пікселі збігаються байт у байт.
- Типова картка 1280×720 зменшилась приблизно з 2,4 МБ до 1,6 МБ (≈ −35 %). Discord швидше завантажує вкладення й показує прев'ю.
- Level 7 обрано свідомо: level 8–9 дають менше 0,3 % виграшу за 1,5–3× CPU на 2 vCPU хості. Кодування займає ~0,3 с на картку всередині наявного render-семафора, результат кешується.
- Фон `discord-welcome-card-night-elf-base.png` перепакований oxipng без втрат (3,45 МБ → 2,39 МБ, RGBA → RGB, бо альфа-канал був повністю непрозорий). Після `ensureAlpha()` пікселі ідентичні, тож рендер не змінився; зменшились репозиторій, Docker-образ і перше читання фону.
- Закруглені прозорі кути 16 px збережено.
- `check:welcome-performance` стежить, щоб фінальний PNG лишався lossless (без `quality`/`colours`/`dither`/`effort`), використовував адаптивну фільтрацію, а фон не роздувався понад 2,6 МБ.
- Hotfix typecheck: прибрано недосяжне порівняння `gateStatus !== "qualified"` у newcomer gate (TS2367), поведінка не змінилась.
