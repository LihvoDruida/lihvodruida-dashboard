# Вирівнювання таймера верхнього банера — 09.10.2026

Оновлено desktop-розмітку таймера праворуч у верхньому банері гільдії.

## Що виправлено

- збільшено розмір цифрових значень таймера;
- збільшено мінімальну ширину кожної колонки часу;
- відкориговано позицію двокрапок між блоками;
- підписи `ДН`, `ГОД`, `ХВ`, `СЕК` вирівняно по центру під відповідними числами;
- нижній рядок із датою та часовою зоною вирівняно по правому краю всього блоку;
- правий блок отримав стабільну ширину, щоб таймер не «стрибав» в композиції.
