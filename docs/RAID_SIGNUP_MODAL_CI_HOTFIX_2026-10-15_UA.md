# Виправлення CI модального запису в рейд — 15.10.2026

Dashboard: **3.8.88**. База: наданий повний архів 3.8.87 із виправленням TypeScript.

## Причина падіння

`npm run build:ci` зупинявся на `npm run audit:styles`. Цей аудит є строгим: невикористані CSS-селектори завершують процес із кодом 1, навіть якщо у виведенні названі кандидатами. Через ланцюжок `&&` наступні кроки та Next.js build не запускалися.

Після переведення запису на модальне вікно в `dashboard/src/app/styles/raids.css` залишилися шість невикористаних класів:

- `.raid-character-picker` — три правила, включно з мобільним і пізнішим перевизначенням ширини.
- `.raid-manual-picker`.
- `.raid-manual-picker__head` — також правила для `strong` та `small`.
- `.raid-manual-picker__hint`.
- `.raid-manual-picker__role`.
- `.raid-manual-picker__row`.

Нотифікація npm про нову основну версію не спричиняла збій.

## Виправлення

1. Видалено всі правила зазначених класів, оскільки в поточному вихідному коді більше немає їхніх споживачів. Стилі позначення учасників із ручним записом залишено.
2. Наступний крок, `audit:ui`, також мав чотири помилки в `RaidAttendanceClient.tsx`: кнопка закриття, два перемикачі способу запису та кнопка скасування не використовували спільну систему кнопок.
3. Кнопку закриття переведено на `btn btn-icon`, перемикачі — на `btn` зі збереженням `is-active`, скасування — на `btn ghost`. Розмір кнопки закриття збільшено до 44×44 px.
4. Версію dashboard і обидва значення версії в lock-файлі піднято до 3.8.88.

Строгість аудитів і порядок `build:ci` збережено. Серверна логіка запису, бот, shared contract, налаштування нагадувань та Docker security overlay не змінювалися.

## Розгортання

Замінити вихідний код на вміст цього повного архіву та повторити звичайний `make up` із кореня проєкту. Контекст Docker-збірки має залишатися коренем проєкту, а не каталогом `dashboard`. На VPS зміни в межах цієї роботи не встановлювалися.
