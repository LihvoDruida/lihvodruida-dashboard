# Банер гільдії — композиція p-masthead

Перероблено банер в архіві версії 3.8.68 за структурою та типографічною шкалою `p-masthead` сайту https://foreverchanges.pro/. Наш лісовий фон і реальні дані гільдії збережено. На робочий сервер зміни не встановлювалися.

## Зміни

- ПК: висота 90 px, центральна назва з симетричними бічними колонками. Прогрес рейду ліворуч; чотири частини таймера, одиниці часу й дата скидання за Києвом праворуч.
- Назва: локальний Cinzel, теплий і бірюзовий відтінки та підпис World of Warcraft. Для кирилиці використовується наявний Spectral SC. Інші шрифтові токени сайту не змінено.
- Мобільний: висота 74 px, назва й підпис ліворуч, компактний таймер днів/годин/хвилин праворуч. Як у референсі, секунди приховано, а на ширинах до 420 px приховано підписи одиниць часу. Прогрес рейду та дата залишаються у версії для ПК.
- На вузькому екрані назва переноситься, а не замінюється трикрапкою. Для 320 px повна назва гільдії займає два рядки.
- Прибрано дубльовані правила таймера, порожній рядок над назвою та обрізання контейнером.
- Скинуто стилі загальних `*-banner`, `*__eyebrow` і `*-label`, які додавали рамку картки, внутрішні відступи та змінювали колір/розмір підписів. Враховано правило `body > *`, щоб банер лишався фіксованим.
- Перемикання банера при прокручуванні, посилання на рейдовий прогрес та обчислення скидання збережено.

## Перевірка

TypeScript, ESLint для змінених TSX/скрипта, check:guild-banner (24 перевірки), check:guild-mobile (14 перевірок) та production-збірка Next.js виконані успішно. Збірка повідомляє про два наявні попередження трасування файлів у discordWelcomeCard.ts, поза цими змінами.

У Chromium запущено справжній GuildStatusBanner.tsx з усіма глобальними CSS у порядку layout.tsx. Для тестової сторінки підставлено лише next/link та приклад даних рейду; таймер і логіка прокручування працюють із вихідного компонента.

Перевірено 14 ширин: 320, 360, 390, 420, 430, 560, 768, 820, 1000, 1001, 1024, 1320, 1440, 1920 px. Жоден видимий елемент банера не виходить за його межі; горизонтальне переповнення відсутнє, помилок JavaScript немає. Додатково перевірено відсутній рейд, довгу назву рейду, українські назви, оновлення таймера, напрям прокручування, відступи фіксованої навігації та зменшення анімації.

Знімки банера наведено поруч із цим файлом. Деталі вимірів — у browser-validation.json. Це локальна перевірка компонента з тестовими даними, без підключення до робочої бази чи Discord.
