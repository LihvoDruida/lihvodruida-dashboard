# 3.8.34 — Welcome card redesign and real member number

## Номер учасника
- Номер на картці більше не хеш від Discord ID. Це порядковий номер учасника на сервері за часом вступу (`joined_at`, при збігу — менший snowflake). Для щойно доданого учасника він дорівнює лічильнику учасників сервера; боти рахуються так само, як у Discord.
- Новий `src/lib/discordMemberJoinNumber.ts`: список учасників кешується на 60 с з дедуплікацією запитів. Новачок, якого ще немає в кеші, примусово оновлює список не частіше ніж раз на 5 с, тож хвиля вступів ділить один запит.
- Уже опублікована картка — статичний PNG, її номер не змінюється. Якщо хтось зі старших учасників вийде, наступні номери зсунуться на одиницю.
- Test lab: поле «Номер» тепер необов'язкове. Порожнє поле для реального User ID дає його справжній номер, без ID — номер наступного учасника. Ручне значення лишається для тестів. Синтетичний тестовий учасник не форсує оновлення списку.

## Дизайн і читабельність
- Нова компоновка зверху вниз: портрет у золотій рамці, золоте привітання, орнаментальний роздільник, великий нік, номер на темній плашці з золотим контуром.
- Шрифти у стилі WoW (OFL, з повною кирилицею та `№`): Spectral SC Bold/ExtraBold для привітання й ніку, Philosopher Bold для підпису. Лежать у `dashboard/assets/fonts/welcome` разом із ліцензіями і копіюються в runtime-образ. Якщо файлів немає, картка рендериться DejaVu і пишеться warn `discord.welcome_card_fonts_missing`.
- Текст читається на яскравому фоні завдяки темному еліптичному scrim за текстовим блоком, віньєтці, м'якому темному контуру, тіні та вертикальному градієнту заливки.
- Довгі привітання та ніки автоматично зменшуються до ширини блоку замість виходу за краї.
- Текст рендериться через Pango (`sharp` text + `fontfile`), користувацький текст екранується. Контур будується з blur без `dilate`/`erode`, бо їхня семантика різниться між релізами Sharp.
- Рамка, роздільник і закруглені кути 16 px запікаються у фон один раз на процес. Кожна картка компонує лише аватар, плашку й три текстові шари, без повноекранних SVG.
- PNG лишається lossless (3.8.33), типова картка ≈1,5 МБ.
