# v3.8.15 — Покращення вибору Discord-тегів

- оновлено спільний `RolePicker` для всіх місць, де вибираються Discord-ролі/теги;
- на ПК список ролей тепер показується у 2 колонки;
- вибрані ролі показуються окремим блоком зверху з лічильником та швидким зняттям через chip;
- пошук оформлено як окремий стилізований рядок;
- картки ролей отримали кращу ієрархію: окремий перемикач, назва, підказка стану та badge праворуч;
- для мобільних лишається одна колонка;
- новий picker підключено також на сторінці формування складу (`/roster`) замість старої простої сітки чекбоксів;
- `RaidRoleMentionPicker` тепер приймає кастомні тексти та коректно синхронізує початкове значення при зміні props.
