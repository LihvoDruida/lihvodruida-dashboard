# Виконання документа пропозицій

Стан вихідного коду: R6.5 / dashboard 3.8.78, 14.10.2026 (Europe/Kyiv). Вихідний діагностичний документ та попередні звіти збережені як історичні; їхні початкові дефекти не переписано заднім числом.

| Етап | Стан | Результат |
|---|---|---|
| R1 | Виконано | Атомарні записи PostgreSQL і обмежені повтори транзакції |
| R2 | Виконано | Збережені операції Discord-публікацій і контрольоване відновлення |
| R3 | Виконано | Серверний каталог профілів, права/фільтри до LIMIT |
| R4 | Виконано | Незалежна пауза очищення, контроль перед відправленням, дедлайни |
| R5 / D04 | Виконано в коді | Чернетки груп, відновлення, явні дії, revision-конфлікти |
| R6.1 | Виконано в коді | Одна дія для імені та Discord-ніку, збережена черга, статус і відновлення |
| R6.2 | Виконано в коді | Один крок для персонажів, мейна й ролі; атомарність, ревізії, чернетка та receipt |
| R6.3 | Виконано в коді | Пам’ять фільтрів і позиції у профілях/заявках, до п’яти подань, повернення до рядка, усунення зайвих переходів |
| R6.4 | Виконано в коді для PostgreSQL | Атомарне перенесення призначень при зміні ID, резервування старих ID, захист старих сесій і підсумок перенесення |
| R6.5 | Виконано в коді | Спільний огляд трьох автоматизацій, розрізнення налаштувань і виконання, збоїв та непевних результатів; переходи до конкретних дій |
| Решта R6 | Наступні окремі релізи | Навігація інших списків, контекстні дії заявок/публікацій та огляд інших автоматизацій |
| R7 | Заплановано | Узгодження дизайну та виміряна оптимізація |
| R8 | Після завершення наявного | Нові наскрізні сценарії |

R6.4 завершив перенесення збережених призначень для нових змін ID у PostgreSQL. Історичні загублені призначення та повний foreign-key контроль legacy-даних не заявлено відновленими. Межі й порядок відкату: [R6.4](R6_4_GROUP_ASSIGNMENTS_2026-10-12.md).

R6.5 додає огляд зі збереженого стану й очікуваних дат, без нових викликів Discord REST або фонового polling. Це знімок на час відкриття; повного heartbeat усіх виконавців не додано. Деталі: [R6.5](R6_5_AUTOMATION_STATUS_2026-10-14.md).
