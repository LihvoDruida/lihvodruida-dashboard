## R7.5 — форма та навігація очищення Discord

**Dashboard 3.8.98 / bot 3.6.9.** Відтворено втрату фокусу після паузи й останнього «Ще», хибний порожній список після збою, застаріле повідомлення про помилку та скидання прапорця при непідтвердженому збереженні. Чернетка призупиняє фонові читання; повторне читання не повторює POST. Пауза перериває очікування збереження, а його пізня відповідь не перезаписує її результат.

У контрольованому сценарії зі 100 рядками один фоновий цикл скоротився з чотирьох запитів сторінок до одного запиту стану без читання рядків. Розгорнутий список явно позначено знімком; окрема кнопка перечитує показані сторінки. Intl.DateTimeFormat використовується повторно. Пагінація відхиляє курсори без прогресу та не змішує різні перевірки.
