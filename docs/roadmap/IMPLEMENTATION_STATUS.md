# Виконання документа пропозицій

Стан вихідного коду: R5 / dashboard 3.8.73, 11.10.2026. Вихідний діагностичний документ та звіти R1–R4 збережені як історичні; їхні початкові дефекти не переписано заднім числом.

| Етап | Стан | Результат |
|---|---|---|
| R1 | Виконано | Атомарні записи PostgreSQL і обмежені повтори транзакції |
| R2 | Виконано | Збережені операції Discord-публікацій і контрольоване відновлення |
| R3 | Виконано | Серверний каталог профілів, права/фільтри до LIMIT |
| R4 | Виконано | Незалежна пауза очищення, контроль перед відправленням, дедлайни |
| R5 / D04 | Виконано в коді | Чернетки груп, відновлення, явні дії, revision-конфлікти |
| R6 | Наступний, кількома релізами | Завершення профілю/ніка, фільтрів, контекстних дій, статусів і відновлення |
| R7 | Заплановано | Узгодження дизайну та виміряна оптимізація |
| R8 | Після завершення наявного | Нові наскрізні сценарії |

Для R6 додатково перевірити безпечне перенесення ручних призначень профілів при зміні ID групи. R5 робить зміну самого документа атомарною та попереджає користувача, але перенесення посилань не заявляє виконаним.
