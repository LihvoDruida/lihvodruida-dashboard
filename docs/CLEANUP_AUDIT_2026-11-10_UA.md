# Очищення Dashboard 3.21.0 — 11.11.2026

Функціональне очищення описане в [окремому звіті](FUNCTIONAL_CLEANUP_2026-11-10_UA.md).

Останній етап: [невикористані операції](UNUSED_OPERATIONS_CLEANUP_2026-11-11_UA.md).

Чинна логіка оновлення оптимізована в [3.21.0](BACKGROUND_REFRESH_OPTIMIZATION_2026-11-11_UA.md).

## Виконано

- Видалено модуль стрімерів і його автоматизацію. Відеофон відновлено та збережено.
- Видалено невикористані `access.ts`, `status.ts`, старий `discordInteractionDedupe.ts`, `ImpersonationToast`, `MobileNavSafeAreaSync`, `PagePrimitives`.
- Тести повторних Discord-команд перенесено на активний `discordInteractionOutbox`; його дані збережені.
- Прибрано три дублікати картинок рейдів із постійними перенаправленнями старих URL та три архівні довідники.
- Прибрано одноразовий імпорт статей, джерела старого сайту, відповідну npm-команду, Docker COPY і пряму Node-залежність `yaml`.
- Видалено старі адреси `/admin` та `/api/admin`, заглушки GitHub-входу, їхні повідомлення і CSP-дозвіл GitHub API.
- Прибрано старий YAML-експорт складу гільдії; чинний sync через API збережений.
- Видалено дубльовану кнопку `RaidPollDeleteButton`; браузерні сценарії використовують активну `RaidPollActions`.

## Що ще потребує рішення

23 історичні JSON-звіти roadmap прибрано. Текстові плани з невиконаними вимогами збережені.
Чинні функції рейдів, пулів, профілів, заявок, прав, Discord-автоматизацій, контенту й моніторингу сервера мають виклики та залежності. Даних, що вони непотрібні користувачам, немає; їх не видаляли.

Публічний Site потрібно перевіряти за його окремим вихідним кодом. Робочі БД та журнал звернень VPS не надані.
